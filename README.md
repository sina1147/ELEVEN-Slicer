# ELEVEN Desktop 1.1 — Windows x64

رفع نمایش نقطه‌نقطه و مثلث‌های پراکنده: سطح کامل، نورپردازی نرم و بافر عمق با Qt OpenGL، بدون VTK.
تغییر ابعاد زنده است و دادهٔ گرافیکی را بازسازی نمی‌کند؛ محاسبات برش و DXF حفظ شده‌اند.

## اگر نسخهٔ 1.0 را دارید

فایل **ELEVEN-Desktop-1.1-Update.zip** (حدود ۲۷ کیلوبایت) را دانلود کنید.
برنامه را ببندید. محتویات ZIP را داخل پوشهٔ فعلی برنامه، کنار ELEVEN.exe کپی کنید و جایگزینی را تأیید کنید.
سپس ELEVEN.exe را اجرا کنید. پوشهٔ runtime و فایل‌های مدل/تنظیمات شما در اصلاحیه تغییر نمی‌کنند.

## نصب تازه

فایل **ELEVEN-Desktop-1.1-Windows-x64.zip** (حدود ۹۴ مگابایت) را دانلود و کامل Extract All کنید.
داخل پوشهٔ ELEVEN-Desktop-1.1، فایل ELEVEN.exe را اجرا کنید.
پایتون و کتابخانه‌ها همراه بسته‌اند؛ نصب جداگانه یا اینترنت هنگام اجرا لازم نیست.

اگر دستگاه درایور OpenGL مناسب نداشت، **RUN_SOFTWARE_GRAPHICS.bat** را اجرا کنید.
این مسیر نیز سطح کامل را نمایش می‌دهد، ولی سرعت آن به پردازنده وابسته است.

## شواهد

۹ تست رگرسیون روی لینوکس و با فایل‌های ویندوز در Wine پاس شدند و پردازش‌ها با کد صفر بسته شدند.
دو تست رندر با مسیر نرم‌افزاری Qt ویندوز نیز پاس شدند.
تست ۸۱٬۹۲۰ مثلث، نبودِ سوراخ در سطح نمایشی و تغییر زندهٔ ابعاد بدون برش‌سازی را بررسی می‌کند.
تمام ۳۲۷٬۶۸۰ مثلث یک مدل تست هم نمایش داده شدند؛ بارگذاری ۲٫۵۲ ثانیه و تغییر اندازه ۰٫۳۶ ثانیه روی رندر نرم‌افزاری محیط مجازی اندازه‌گیری شد.
این اعداد تضمین سرعت روی دستگاه شما نیستند. سیستم ویندوز واقعی کاربر هنوز در این محیط در دسترس نیست.

موتور F3D/VTK اضافه نشده است. تفاوتِ تعیین کیفیت در مدل‌های بالای ۲۰۰هزار مثلث از نسخهٔ 1.0 همچنان برقرار است؛ توضیح در راهنمای ZIP.
کد main مخزن تغییر نکرده است. SHA256 فایل‌ها همراه این تحویل است.
