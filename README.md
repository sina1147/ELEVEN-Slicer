# ELEVEN Desktop 1.2 — cumulative CPU display update

رفع وابستگی مسیر پیش‌فرض به OpenGL برای مشکل پنجرهٔ سفید در نسخهٔ 1.1.
این نسخه، سطح کامل را با رندر CPU بومی و بافر عمق نمایش می‌دهد؛ ایجاد QOpenGLWidget یا OpenGL context لازم نیست.
علت دقیق خطای درایور روی دستگاه کاربر در دسترس نیست؛ این اصلاحیه مسیر وابسته به آن را کنار می‌گذارد.

## اعمال روی نسخهٔ 1.0 یا 1.1

فایل **ELEVEN-Desktop-1.2-Update.zip** (حدود ۱۱۶ کیلوبایت) را دانلود کنید.
برنامه و پنجرهٔ سفید را ببندید. همهٔ محتویات ZIP را در پوشهٔ فعلی برنامه، کنار ELEVEN.exe کپی و جایگزین کنید.
فایل **app/cpu_raster.dll** هم باید کپی شود؛ تنها فایل‌های Python را انتخاب نکنید.
سپس **ELEVEN.exe** را اجرا کنید. نصب پایتون یا کتابخانهٔ تازه لازم نیست.

RUN_SOFTWARE_GRAPHICS.bat نیز اکنون CPU واقعی را انتخاب می‌کند؛ دیگر QT_OPENGL=software نیست.
در راهنما → گزارش نمایش باید نسخهٔ 1.2 و CPU rasterizer (no OpenGL) دیده شود.
RUN_GPU_GRAPHICS.bat گزینهٔ اختیاری برای دستگاهی است که مسیر OpenGL آن سالم باشد؛ برای رفع پنجرهٔ سفید لازم نیست اجرا شود.

## بررسی‌ها

۱۱ تست روی لینوکس بدون نمایشگر و با پایتون ویندوزِ داخل بسته در Wine پاس شدند و با کد صفر تمام شدند.
تست ویندوز با QT_OPENGL=software هم اجرا شد؛ مسیر CPU بدون OpenGL رابط را نقاشی کرد.
تست‌ها شامل بازشدن رابط بدون OpenGL، ترتیب بافر عمق مستقل از ترتیب مثلث‌ها، سطح پیوستهٔ ۸۱هزار مثلثی، تغییر زندهٔ ابعاد و ۲۴ مقایسهٔ هندسی با اصل هستند.
تمام ۳۲۷٬۶۸۰ مثلث مدل تست نمایش داده شد؛ زمان تغییر اندازه در محیط تست حدود ۰٫۲۹ ثانیه بود. سرعت روی دستگاه کاربر اندازه‌گیری نشده است.
کد برش و DXF تغییر نکرده است. مدل و تنظیمات شخصی کاربر در اصلاحیه نیستند و تغییر نمی‌کنند.
سورس رندر C و تست‌ها داخل ZIP هستند. SHA256 همراه تحویل قرار دارد.
