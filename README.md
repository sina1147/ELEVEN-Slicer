# ELEVEN Desktop 1.0 — Windows x64

نسخهٔ قابل‌حمل ساخته‌شده از فایل mesh2dxf.py ارسالی، با رابط فارسی مستقل.

## دانلود و اجرا

فایل **ELEVEN-Desktop-Windows-x64.zip** را باز کنید و دکمهٔ **Download raw file** را بزنید.
ZIP را کامل با Extract All استخراج کنید و از پوشهٔ ELEVEN-Desktop، فایل ELEVEN.exe را اجرا کنید.
پوشه‌های app و runtime باید کنار فایل اجرایی بمانند. نصب جداگانهٔ Python یا اینترنت لازم نیست.
این بسته برای Windows 10/11 روی x64 است.

## بررسی‌ها و محدودیت‌ها

۷ تست روی لینوکس و با پایتون ویندوزِ داخل بسته در Wine پاس شدند؛ ۲۴ حالت هندسی با اصل مقایسه شدند.
خود فایل اجرایی نیز رابط برنامه را باز کرد. ویندوز واقعی هنوز آزمایش نشده است.
در مدل‌های بالای ۲۰۰هزار مثلث، تعداد/فاصلهٔ خودکار دنده‌ها ممکن است متفاوت شود:
اصل از مدل ساده‌شدهٔ VTK برای تعیین کیفیت استفاده می‌کند و این نسخه از مدل کامل.
توضیحات، سورس و تست‌ها داخل ZIP هستند. منطق شاخهٔ main در این تحویل تغییر نکرده است.

فایل SHA256 همراه بسته برای بررسی سلامت دانلود است.
