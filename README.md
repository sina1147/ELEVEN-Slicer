# ELEVEN PROJECT 1.3 update

Download ELEVEN-PROJECT-1.3-Update.zip. Close the app, copy all ZIP contents beside ELEVEN.exe and replace existing files. Requires version 1.2.

DXF includes original arranged parts and a separate overlapping assembly copy, red numeric labels at height 12, shared registration center and one DXF group per part in each arrangement. The model preview direction line is thicker.

The label insertion point is inside the largest island. Extremely small or narrow shapes may not physically contain text of fixed height 12.
